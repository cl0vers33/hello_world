## 四、关键代码

摘自 [lib/main.dart](../lib/main.dart) 第 3-5 行与第 7-36 行，逐行解释如下：

```dart
void main() {
  runApp(const MyApp());
}
```

- 第 3 行：`main` 是 Dart 程序入口，操作系统启动应用时第一个调用的函数。
- 第 4 行：`runApp` 把根组件 `MyApp` 挂载到屏幕上；`const` 表示 `MyApp` 是编译时常量，Flutter 据此做组件复用与性能优化。
- 第 5 行：函数体结束。

```dart
class MyApp extends StatelessWidget {
  const MyApp({super.key});
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Flutter Demo',
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.deepPurple),
      ),
      home: const MyHomePage(title: 'Flutter Demo Home Page'),
    );
  }
}
```

- `class MyApp extends StatelessWidget`：`MyApp` 是无状态组件，界面不随交互改变；继承 Flutter 的 `StatelessWidget`。
- `const MyApp({super.key})`：构造函数，`super.key` 把 key 透传给父类，用于组件复用与更新识别。
- `Widget build(BuildContext context)`：`build` 方法返回组件树，描述界面长什么样；`BuildContext` 是组件在树中位置的句柄。
- `MaterialApp(...)`：Material 风格应用容器，提供主题、路由等基础能力。
- `title`：应用在任务切换器中显示的标题。
- `ThemeData(colorScheme: ColorScheme.fromSeed(seedColor: Colors.deepPurple))`：基于种子色 `deepPurple` 生成完整配色方案。**AI 辅助生成**：原模板文件此处类名缺失，AI 起草注释时补全为 `ColorScheme.fromSeed`。
- `home: const MyHomePage(title: 'Flutter Demo Home Page')`：指定首页为 `MyHomePage`，传入标题字符串。

> 是否 AI 生成：是（注释由 AI 辅助起草，本人逐行核对；代码逻辑保持 `flutter create` 原样，仅修正两处类名缺失）。

### 检查点5：口头解释 runApp 与 Widget

- `runApp`：Flutter 框架的入口挂载函数，把传入的根组件（这里是 `MyApp`）挂到屏幕上，启动组件树的渲染与调度。等价于"把根 Widget 作为整棵 UI 树的根"。
- `Widget`：Flutter 描述界面的基本单位。一切界面元素（`Text`、`Button`、`Scaffold`、`MaterialApp`）都是 Widget；Widget 是不可变的配置描述，真正的渲染由对应的 `Element` 与 `RenderObject` 完成。可以理解为"Widget 是图纸，Element 是按图纸搭的实体，RenderObject 是真正量尺寸画像素的那一层"。

## 六、问题与调试

> 详细记录见 [任务2_flutter_doctor问题定位与修复记录.md](任务2_flutter_doctor问题定位与修复记录.md)

### 问题1：Gradle 下载 SSL 证书验证失败

- **现象**：`flutter run -d emulator-5554` 时报 `javax.net.ssl.SSLHandshakeException: PKIX path building failed`。
- **定位**：Gradle wrapper 从 `services.gradle.org` 下载 Gradle 9.3.1 发行版，Java truststore 不识别其证书链。
- **解决**：`gradle-wrapper.properties` 改 `distributionUrl` 为 `https://mirrors.cloud.tencent.com/gradle/gradle-9.3.1-all.zip`；`settings.gradle.kts` 的 `repositories` 前置阿里云 Maven 镜像。
- **验证**：再次运行，Gradle 成功下载，进入编译阶段。

### 问题2：项目路径含非 ASCII 字符

- **现象**：SSL 修复后构建仍失败，报 `Your project path contains non-ASCII characters`。
- **定位**：项目路径 `...\作业\移动应用开发实践\课程1\hello_world` 含中文，Android Gradle Plugin 拒绝。
- **解决**：`android/gradle.properties` 追加 `android.overridePathCheck=true`（按报错提示的官方开关）。
- **验证**：再次运行，构建通过，应用在模拟器启动。
